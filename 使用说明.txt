========================================================
   壁纸提取工具  --  使用说明
========================================================


一、这是干嘛用的？

   你在 Wallpaper Engine 里下载了壁纸，打开文件夹一看，
   里面是个叫 scene.pkg 的文件。

   资源管理器里能看到缩略图，但这个 pkg 文件你双击打不开
   —— 它不是压缩包，是 Wallpaper Engine 自己的格式，
   右键也没有"解压"。

   想把壁纸存成一张普通图片，找不到办法。

   这个小工具就是干这个的：把 pkg 里的原图拿出来，
   变成一张你能正常打开、能设成壁纸、能丢进 PS 的图片。

   而且拿出来的是原图，不是截图、不是缩略图，画质不掉。


二、怎么用？

   把 pkg 文件拖到「run.bat」上面，松手。完事了。

   图会出现在 output 文件夹里，还会自动帮你打开。

   不想拖也行：把 run.bat 和 pkg 放同一个文件夹，
   双击 run.bat，它会自己找到。

   （run.bat 是 Windows 用的。Mac 和 Linux 看第十节。）


三、去哪找 pkg 文件？

   D:\Steam\steamapps\workshop\content\431960\

   里面每个数字文件夹是一张壁纸。
   （盘符按你自己 Steam 装的位置来。）

   找到带 scene.pkg 的那个文件夹，把 scene.pkg 拖出来用。


四、哪些能提，哪些不能提

   拖进去的东西        能出图吗    说明
   ────────────────    ────────    ──────────────────
   scene.pkg            能         场景壁纸，最常见
   .tex 文件            能         图片就藏在里面
   整个壁纸文件夹        能         自动找里面的 pkg
   preview.jpg          不用提     本来就是图，但比较糊
   .mp4 / .webm         不能       视频壁纸，没有 pkg
   index.html / .exe    不能       网页壁纸 / 程序壁纸

   --- 怎么分辨自己是哪种？打开壁纸文件夹看一眼 ---

   有 scene.pkg      ->  场景壁纸，拖它             能提
   只有 xxx.mp4      ->  视频壁纸                   不能提
   有 index.html     ->  网页壁纸                   不能提
   有 xxx.exe        ->  应用程序壁纸                不能提

   --- 那三种不能提的，图怎么弄？ ---

   视频壁纸     里面一般有个 preview.jpg 能直接用；
                想要高清的就用 ffmpeg 截一帧：
                ffmpeg -i 视频.mp4 -vframes 1 out.jpg

   网页壁纸     图片本来就散在文件夹里（比如 imgs 目录），
                直接拷出来就行，不用提取

   应用程序壁纸  是个小游戏，没有"壁纸图"这回事，拿不到

   拖错文件上去不会出错，工具会告诉你这是哪种、该怎么办。


五、结果在哪？

   就在 run.bat 旁边，会自动新建一个叫 output 的文件夹，
   东西都在里面。


六、需要装什么吗？

   需要 Node.js。下载地址：https://nodejs.org/

   装的时候一路点"下一步"就行。装完之后 run.bat 才能用。

   不用联网，不用管理员权限，不用装别的软件。


七、这个文件夹里都有啥？

   run.bat          你要拖的就是它
   使用说明.txt     就是这个文件
   技术细节.txt     想研究原理的时候再看，平时不用管
   pkg.mjs          解包的程序
   tex.mjs          提图的程序
   README.md        英文说明（GitHub 上显示用）

   （如果你是从别人那儿拿到的完整包，可能还会多出
     output\ 或 images\ 之类的文件夹，那是已经提好的图。）


八、提出来的图会掉画质吗？

   不会，一点都不会。

   因为 Wallpaper Engine 的 tex 文件里，装的就是一张完整的
   PNG 或 JPEG 图片。本工具只是把这张图原样拿出来，没有做
   任何转换。

   （有些工具会先转换一遍再存，反而白白损失画质。）


九、有提不出来图的情况吗？

   有，两类：

   1. 类型不对
      上面第四部分那张表里写了，视频壁纸、网页壁纸、
      程序壁纸都没有 pkg，提不了。

   2. 特效遮罩图
      水波、光晕那种灰灰的遮罩图，测试的 70 个纹理里有
      27 个提不出来。但这不影响你要的壁纸，壁纸本体都能提。


十、Mac / Linux / 想敲命令的

   用这两个脚本（需要装 Node.js）：

     解包：  node pkg.mjs scene.pkg --extract out/
     提图：  node tex.mjs out/ --out images/

   也可以直接处理一整个文件夹：

     node pkg.mjs "壁纸文件夹" --extract out/
     node tex.mjs out/ --out images/

   只想看看包里有什么，不解包：

     node pkg.mjs scene.pkg
